# 数据来源与合规声明

## 一、数据来源

- 数据源：**Inside Airbnb** —— https://insideairbnb.com/get-the-data
- 地区：美国纽约州 Albany（Capital District 区域）
- 文件：`listings.csv.gz`（房源主表）、`reviews.csv.gz`（评论明细）
- 获取时间：2026-11（课程作业指定数据集）

## 二、获取方式

- 由项目作者从 Inside Airbnb 官方页面**直接下载** xlsx 文件，未使用任何爬虫、抓取脚本、API 或绕过访问控制的手段。
- 未登录、未上传个人信息、未批量镜像网站。

## 三、授权与用途

- Inside Airbnb 数据采用 **CC BY 4.0**（Creative Commons Attribution 4.0 International）许可发布，允许在署名条件下自由使用、复制、修改与再分发。
- 本项目仅用于嘉兴大学《商业数据分析》课程的**期末作业学术研究**，不用于任何商业目的。
- 论文与大屏中已注明数据来源。

## 四、隐私与伦理

- 评论明细仅使用 `listing_id`、`date` 两个字段，未使用评论正文、评论者昵称或任何可识别个人身份的信息。
- 房源数据为平台公开挂牌信息，本分析不涉及对任何房东或客人的评价。
- 所有统计结果为聚合层面，不指向任何个人。

## 五、复现说明

- 原始数据文件保留在 `data/raw/`（listings.xlsx / reviews.xlsx）。
- 完整清洗与分析流程见 `scripts/01_load.py ~ 05_dashboard.py`，可通过 `python run_all.py` 一键复现。
